## Kopi Nusantara – Coffee Shop Website

A group project website created for the Web Design subject in the Information Systems program at President University.
This project delivers an authentic online experience for coffee lovers through a modern coffee shop website built with HTML, CSS, and JavaScript.

Project Overview

## Kopi Nusantara is a coffee shop website designed with:

Structured pages using HTML

Styling and layout with CSS

Interactive features powered by JavaScript & jQuery

The website includes navigation, product showcase, feedback forms, authentication pages, and a checkout/cart system.

Note: This website is currently optimized for laptop displays and is not fully responsive yet.

 ## Main Features

Frameset-based homepage layout

Navigation bar with search & cart icons

Hero landing section

About Us page with parallax scroll animation

Product slider/carousel page

Contact form with validation (SweetAlert2)

Feedback survey form (radio, checkbox, dropdown)

Login, Register, Forget Password pages

Checkout cart system with total price calculation
